# Om's Simple Portfolio

A clean beginner-friendly portfolio website made using only HTML and CSS.

## Files
- index.html
- style.css

## Concepts demonstrated
- Semantic HTML
- Navigation
- IDs and classes
- Flexbox
- CSS Grid
- Box Model
- Position: sticky
- Hover effects
- CSS transitions
- Forms
- Responsive design
- Media queries

## How to run
Open `index.html` in a browser.

No JavaScript or external libraries are required.
